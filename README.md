🚀 CareerCompass AI

Your Daily AI Career Coach & Growth System

---

🌟 Overview

CareerCompass AI is an AI-powered career growth platform that goes beyond traditional career advice.

Instead of giving long, generic guidance, it provides:

* 🎯 Clear career direction
* 📅 Daily actionable plans based on your time
* 🎮 Gamified progress tracking (XP, streaks, levels)
* 💰 Earning-focused guidance
* 🌟 Personalized motivation

👉 The goal is simple:
Help users move from confusion → consistency → real income

---

🔥 Problem Statement

Most career guidance platforms:

* Give long, overwhelming advice ❌
* Don’t provide daily execution steps ❌
* Lack motivation & accountability ❌
* Don’t help users reach earning stage ❌

---

✅ Solution

CareerCompass AI solves this by acting as a:

🧠 AI Career Coach

📅 Daily Planner

🎮 Growth Tracker

💰 Income Guide

It guides users every single day, not just once.

---

🚀 How It Works

1. User signs up / logs in
2. Enters:

   * Career interest
   * Skill level
   * Daily hours
3. AI generates:

   * 🎯 Direction
   * 📅 Daily plan
   * 🔥 Main mission
   * 📊 Progress system
   * 💰 Earning guidance
4. User follows daily tasks
5. Progress updates over time

📦 Installation & Setup

1. Clone Repository

```bash
git clone https://github.com/your-username/careercompass-ai.git
cd careercompass-ai
```

---

2. Install Dependencies

```bash
npm install
```

---

3. Setup Firebase

Go to Firebase Console
Create a new project
Enable:

   Email/Password Authentication
   Google Sign-In

Add your Firebase config:

```js
const firebaseConfig = {
  apiKey: "YOUR_KEY",
  authDomain: "YOUR_DOMAIN",
  projectId: "YOUR_ID",
};
```
```

### 4. Run the App

```bash
npm start
```
